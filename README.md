# 🌍 SILTOUR – Plataforma Informativa Turística

Aplicación web estática orientada a mostrar información relevante sobre turismo, salud, educación y servicios en diferentes ubicaciones. Diseñada para facilitar el acceso a información organizada para usuarios y visitantes.

---

## 🚀 Características

* 📍 Información turística (lugares, cultura, actividades)
* 🏥 Sección de salud (hospitales y centros médicos)
* 🎓 Información educativa
* 🍽️ Restaurantes y sitios de interés
* 🏃 Actividades deportivas
* 📄 Navegación sencilla entre secciones

---

## 🛠️ Tecnologías utilizadas

* HTML5
* CSS3
* JavaScript (básico)

## 📂 Estructura del proyecto

* `index.html` → Página principal
* `tourism.html` → Información turística
* `health.html` → Servicios de salud
* `education.html` → Información educativa
* `restaurants.html` → Restaurantes
* `sports.html` → Actividades deportivas
* `static/` → Archivos CSS e imágenes

adémico finalizado, desarrollado como práctica de estructura web y organización de contenido.
